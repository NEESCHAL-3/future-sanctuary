# From 2026 to the Future: A Personal Sanctuary

A digital sanctuary and time capsule created in 2026 by Neeschal, born in 2005 in Nepal. This project serves as a permanent, open-source vault for human reflections, promises, and warmth intended for generations yet to come.

## Architecture

This project was built to endure and function seamlessly without complex server dependencies, utilizing core web technologies and a lightweight infrastructure:

- **Frontend**: Vanilla HTML5, CSS3, and ES6 JavaScript. No heavy frameworks were used in order to maintain extreme performance and long-term codebase stability.
- **Visuals**: Procedural 60fps HTML5 Canvas particle engines (Hope Rain) and 3D CSS transform matrices for tactile glassmorphism.
- **Audio**: Custom Web Audio API synthesizers producing generative ambient waveforms (55Hz drone with LFO automation).
- **Backend**: Supabase (PostgreSQL) for permanent, frictionless storage of user-submitted letters and global interactions.

## The Letters Vault

The core feature of this sanctuary is the Letters Vault. It allows anyone on Earth to inscribe an anonymous message to specific audiences (Students, Teachers, Future Children, Laborers, Healers, Family, Friends, or Love). These letters are permanently etched into a database, accessible for future generations to read and reflect upon.

## Open Source Philosophy

This codebase is completely open source. It is left here as a digital artifact. Future developers, students, and engineers are encouraged to study the procedural canvas algorithms, the Web Audio integration, and the architectural decisions made in 2026.

May this sanctuary serve as a reminder to protect our planet, honor human labor, and leave open doors for those who follow.
